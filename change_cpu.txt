  Firmware memory map the C program uses

  #define SDR_TX_DATA  (*(volatile uint32_t *)0x10000000)  // write → send packet
  #define SDR_TX_READY (*(volatile uint32_t *)0x10000004)  // 1 = ready for next write
  #define SDR_RX_DATA  (*(volatile uint32_t *)0x10000008)  // read → receive (clears valid)
  #define SDR_RX_VALID (*(volatile uint32_t *)0x1000000C)  // 1 = packet waiting

  To synthesize
  1. Add the four new .sv/.v files in rtl/cpu/ to your Vivado project (Sources → Add)
  2. make install in firmware/ whenever you change the C code (copies fresh hex) 
  3. Re-run synthesis — PicoRV32 will consume roughly 1500 LUTs on U280
